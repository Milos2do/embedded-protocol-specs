# Embedded Protocol Specifications (EPS)

Standardized interface specifications and security baselines for lightweight telemetry, rate limiting, and transport security across distributed embedded nodes.

## Maintained Specifications

- `specs/api-rate-limiting.md`: Exponential backoff and token bucket controls.
- `specs/distributed-tracing.md`: W3C tracecontext and span propagation.
- `specs/tls-handshake.md`: Hardened transport-layer requirements for low-power devices.
- `specs/graceful-shutdown.md`: Signal trapping and in-flight drain semantics.

## Collaboration

Maintained jointly by working group contributors. Submit RFC pull requests against `main`.
